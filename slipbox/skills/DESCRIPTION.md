# slipbox — CARP skills

The interactive flows of the slipbox knowledge base. They need the conversation
and the agent's judgement; the deterministic mechanics live in the `slipbox_*`
tools.

**CARP write path + read path:**
- **capture** — Stage 1: store a shared source in `inbox/` verbatim.
- **adapt** — Stage 2: distil a capture into atomic notes in `stage/`.
- **review** — Stage 3: the human quality gate; accept/reject per-source batches.
- **link** (alias **persist**) — Stage 4: place an accepted atom in the store.
- **search** — the read path: answer with claim-by-claim citations.

**Higher-level workflows:**
- **triage** — sweep the whole inbox backlog end-to-end (interactive auto-adapt).
- **readapt** — re-read a source's archived original with a better model and
  propose additional atoms without polluting the store.
- **consolidate** — maintain the topic-map / bookmark hierarchy periodically.
- **oversight** — admin domain-drift oversight from per-contributor scope stats.
